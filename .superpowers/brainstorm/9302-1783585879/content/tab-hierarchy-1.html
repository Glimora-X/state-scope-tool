StateScope Cockpit

第二部分只定义 7 个 Tab 的新层级。保留全部信息，不删能力，只改变优先级、进入时机和交互方式。

Seven Tabs · Priority and Interaction Model
Tier 1 · Primary flow
Daily inspection path
1. Overview
启动门禁、会话身份、最新证据、风险队列、快捷操作都在这里聚合。
2. Epoch Timeline
从概览进入单个 Epoch 的纵向调查，专注时间顺序和上下文切换。
3. Diff Workspace
从风险条目或时间线跳转进来，做双轨比对和字段级核查。
Tier 2 · Extended validation
When the session is stable
4. Cutover Report
不是首页主角，但保留所有累计字段、导出和 allowlist 视角。
5. Scenario Regression
从“工作台”改成“任务面板”，场景步骤、PASS/BLOCK、签字都保留。
6. Issues
从风险升级而来，保留本地 Issue、Jira、筛选、导出，但不再和首页抢注意力。
Tier 3 · Control surface
Configuration and recovery
7. Settings
调试开关、Profile、Allowlist、Jira 全部保留，但默认只在“概览门禁失败”时被强提示。
Interaction changes
What changes without losing data
把“空状态解释”改成可执行门禁卡和 CTA
把“异常列表”改成风险队列，点击后仍然跳 Diff
把“概览中的 timeline”改成压缩预览，完整调查仍去 Timeline Tab
把“场景回归和 Issues”从平铺工具页改成更明确的任务/工单面板
保留所有复制、导出、筛选、签字、同步能力，只改变入口位置和强调程度
Navigation behavior
Cross-tab jumps
Overview risk item → Diff Workspace
Overview epoch preview → Epoch Timeline
Mismatch escalate → Issues
Scenario pass/block summary → Scenario Regression
Readiness failure → Settings exact section
